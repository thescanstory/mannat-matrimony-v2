# Mannat Matrimony — Claude Code Guide

## Project Overview
Mannat is a luxury, intention-first Indian matrimonial matchmaking web & mobile application built with React 19, Vite, Tailwind CSS, Capacitor iOS/Android, and Supabase.

## Apple App Review Guideline 2.1 (Information Needed)
- **App Version:** 1.0 (Build 2)
- **Live Review Portal:** `https://mannatmatrimony.com/app-review.html`
- **Review Video:** `https://mannatmatrimony.com/app-review-demo.webm`
- **Demo Reviewer Login:** `rahul@mannat.vip` (1-Tap Email sign-in, pre-verified)

## Commands for Claude Code
- `/app-review` — Retrieve the full ready-to-paste Apple App Store Connect Resolution Center response and notes.
- `npm run build:ios` — Build Vite frontend and sync Capacitor iOS project.
- `node scratch/record_apple_review_flow.js` — Automated Playwright screen recording generator on iPhone viewport.
